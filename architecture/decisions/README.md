# Architecture Decision Records

**Format and policy.** Every ADR follows the Nygard format we used in A2: a header with *Status*, the decision area it answers and the deciders, then *Context*, *Decision*, *Alternatives considered*, *Consequences* (positive, negative, risks), the brief's questions answered for that decision, and a closing *How we will know if this is wrong* section that names the observation (a ledger pattern, a run outcome or an experiment result) that would make us revisit it. ADRs are never edited to reverse a decision. If a run or an experiment shows that a decision was wrong, the old ADR stays in this folder with its status changed to **Superseded by ADR-0xx**, and the new ADR explains what that run taught us and links back to the evidence in `results/runs.md`. `DESIGN.md` is the summary of the current decisions; when it and an ADR disagree, the ADR wins and `DESIGN.md` is updated. All 13 ADRs are **Accepted**. ADR-013 records our *interpretation* of the brief's "at most twice / two review rounds"; if course staff or our runs show a different reading is intended, it will be superseded. A design change found by review before any run (not a run result) is recorded as a dated revision note inside the ADR instead of a supersession (ADR-006, run cap $8 → $10).

## Open refinements recorded in ADRs that DESIGN.md adopted

These ADR refinements of `DESIGN.md` are now reflected in `DESIGN.md`.

- **ADR-006, budget reservation (refines DESIGN §7).** A rework starts only if one Reviewer cap ($2) still fits under the run cap after it; otherwise the last review stands and the run ends `awaiting-human`. Adopted in DESIGN §7 and §10 ("Reviewer reservation"). ADR-006's 2026-11-24 revision note then raised the run cap from $8 to $10, also adopted in DESIGN.
- **ADR-010, concurrency key (refines DESIGN §11).** Only real trigger events are grouped on the issue number; every other event is grouped on `github.run_id`, so unrelated comments cannot cancel a queued run. Adopted in DESIGN §11, after which ADR-010's "refines DESIGN §11" note was removed.
