# Token and cost accounting

The brief asks for the total number of tokens used. This file sums them. Generated by `experiment/scripts/tokens.py` over every saved ledger (command at the bottom).

**What "cost" means here (ADR-014).** No Anthropic or OpenAI API was billed. Agents ran on the student's **ChatGPT subscription** (Codex CLI) and **Google Antigravity subscription** (agy). The `notional $` column is an *assumed list-price equivalent* computed from tokens (`workflow/autose/backends.py: NOTIONAL_PRICES`). It exists only so the run cap of ADR-006 still means something; it is not money spent. The real limit was the **subscription usage quota**. The ChatGPT quota ran out at ~13:45 UTC on 2026-11-24 after ~45 min of concurrent CI and local use (see `runs.md`). Antigravity's Claude/GPT-OSS quota ran out at about the same time; its Gemini quota did not. After the ChatGPT quota reset, 12 more GitHub runs were made on 2026-11-24 15:54–16:08 UTC with the smaller default models of ADR-014 note 2 (builders and judge `gpt-6.1-terra`, reviewer and verifier `gpt-6-luna`): 14 ledgers, 29 calls, 753,374 tokens in, 71,684 out, 2,295,424 cached, notional $1.30. Kind `E1-CI` marks `/autose review` runs on the seeded PRs (#7–#11); the earlier five of these failed on the quota and have 0-token rows. There is no provider console figure to cross-check, because subscriptions report no per-token bill.

**Cache.** `cache_read` is the provider's cached-input count. Neither CLI reports cache *writes*, so `cache_write` is always 0. `tokens_out` includes reasoning/thinking tokens.

**Not in the ledgers.** These calls are not counted:
- canary calls
- the ~10 smoke/probe calls used to check the CLIs
- calls that failed on the quota before returning usage (they show as 0-token rows)
