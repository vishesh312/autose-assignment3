## Notes

- Bugs 1 and 2 are **real**. Both reproduce at the pin `edff96a`, which is upstream `master` HEAD as of 2026-11-24, so there are no later upstream commits. Neither has a merged upstream fix yet. The references are an open upstream issue with an open PR (#639/#643) and an open PR (#650). No bug was injected, so the fork's `main` needs no extra commit for these.
- Upstream references in the issue bodies are written in backticks (for example `` `msiemens/tinydb` issue `#639` ``) so that GitHub does **not** auto-link them. An auto-link would add a cross-reference event to the upstream project, and the rules forbid touching upstream.
- The issue texts are written in the user's voice. Bug 1 mentions upstream #639, and features 3 and 4 mention the old upstream requests, the way a real user would link them. The bodies never describe the fix.
- Hidden tests for issue 5 test the **maintainer answer**. Without the answer, the issue is deliberately not testable.
